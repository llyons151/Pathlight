A few good questions.

What is Pathlight?+

Pathlight is an analytics platform in development. It’s designed to combine website behavior tracking with AI-assisted exploration, so you can identify friction and plan improvements.

Is this real website data?+

No. This interactive preview uses illustrative sample data. Change the reporting period, explore the insights, or ask a question to try the concept. No website is connected.

Can AI really tell me why users leave?+

Behavior can reveal patterns, but it can’t prove intent. Pathlight’s approach is to offer possible explanations backed by observations, then help you validate them with user feedback and experiments.

Can I connect my website yet?+

Not yet. This is a product preview. Website integration, live tracking, and connected AI analysis are still to be built.
